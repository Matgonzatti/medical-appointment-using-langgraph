# Medical Appointment Assistant

A conversational agent for scheduling and cancelling medical appointments, built with [LangGraph](https://langchain-ai.github.io/langgraphjs/) and language models via [OpenRouter](https://openrouter.ai/).

The system receives a natural language message (e.g. _"I'd like to schedule an appointment with Dr. Alicio da Silva tomorrow at 4pm"_), identifies the user's intent and performs the corresponding action (schedule or cancel), returning a natural language response generated by the agent itself.

## How it works

The flow is modeled as a state graph (`StateGraph`) with the following nodes:

```
START → identifyIntent ─┬─► schedule ─┐
                         ├─► cancel  ─┼─► message → END
                         └─► (unknown)─┘
```

- **`identifyIntent`**: uses the LLM to extract the intent (`schedule`, `cancel` or `unknown`), the professional, the date/time and the reason for the appointment from the user's message.
- **`schedule`**: validates the extracted data and books the appointment through the `AppointmentService`.
- **`cancel`**: validates the extracted data and cancels the appointment through the `AppointmentService`.
- **`message`**: uses the LLM to generate the final response to the user based on the outcome of the action (success or error).

If the intent cannot be identified or an error occurs during extraction, the flow is routed directly to the `message` node, which generates an appropriate response.

### Graph state

The state (`GraphState`) flows between nodes and accumulates:

- `messages`: message history (human/AI);
- `intent`, `professionalId`, `professionalName`, `datetime`, `reason`, `patientName`: data extracted from the user's intent;
- `actionSuccess`, `actionError`, `appointmentData`: result of the schedule/cancel action;
- `error`: error that occurred while identifying the intent.

## Project structure

```
src/
  config.ts                    # Model configuration (OpenRouter)
  index.ts                     # HTTP entry point
  server.ts                    # Fastify server with the POST /chat route
  graph/
    factory.ts                 # Builds the graph with its dependencies (LLM + AppointmentService)
    graph.ts                   # StateGraph and state definition
    nodes/
      identifyIntentNode.ts    # Identifies the user's intent
      schedulerNode.ts         # Schedules the appointment
      cancellerNode.ts         # Cancels the appointment
      messageGeneratorNode.ts  # Generates the final response to the user
  prompts/v1/
    identifyIntent.ts          # Prompts + schema (Zod) for intent identification
    messageGenerator.ts        # Prompts + schema (Zod) for message generation
  services/
    appointmentService.ts      # Appointment business rules (in-memory data)
    openRouterService.ts       # LLM client (OpenRouter) with structured output
tests/
  router.e2e.test.ts           # End-to-end tests for the schedule/cancel flow
```

## Prerequisites

- Node.js >= 24.10.0
- An [OpenRouter](https://openrouter.ai/) API key

## Setup

1. Copy the environment variables file:

   ```bash
   cp .env.example .env
   ```

2. Fill in the `.env` with your OpenRouter key (and, optionally, LangSmith credentials for tracing):

   ```
   OPENROUTER_API_KEY=your_openrouter_api_key_here

   LANGSMITH_API_KEY=your_langsmith_api_key_here
   LANGCHAIN_TRACING_V2=true
   LANGCHAIN_PROJECT=03-medical-appointment
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

## Running

Start the HTTP server:

```bash
npm start
```

Development mode (with watch and inspector):

```bash
npm run dev
```

Run via [LangGraph CLI](https://langchain-ai.github.io/langgraphjs/) (uses `langgraph.json`):

```bash
npm run langgraph:serve
```

## Usage

The server exposes a single route:

### `POST /chat`

```bash
curl -X POST \
  -H 'Content-type: application/json' \
  --data '{"question": "Sou Maria Santos e quero agendar uma consulta com Dr. Alicio da Silva para amanhã às 16h para um check-up regular"}' \
  http://localhost:3000/chat
```

Cancellation example:

```bash
curl -X POST \
  -H 'Content-type: application/json' \
  --data '{"question": "Cancele minha consulta com Dra. Ana Pereira que tenho hoje às 14h, me chamo Joao da Silva"}' \
  http://localhost:3000/chat
```

The response contains the final graph state, including the identified `intent`, the outcome of the action (`actionSuccess`/`actionError`) and the list of `messages` (with the response generated by the agent).

## Tests

npm test          # runs all tests
